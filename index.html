The Nightmare Data Model

A Power BI model built from a messy 23-sheet Excel export covering sales, inventory, campaigns, order processing and targets.

Challenge
Related data was scattered across 23 sheets, with test records and duplicate products. A report on top of it could look right while its totals were inflated.
Approach
Split the data into six shared dimensions and six facts, each with a defined grain, and added a role that limits customer data by region.
Result
A model where every fact is filtered through the same dimensions, so totals can be checked and relationships are easy to follow.

  • Power Query
  • DAX
  • TMDL / PBIP
  • Row-level security

AdventureWorks Sales Report

An interactive Power BI report on sales for AdventureWorks, a fictional bike and outdoor-equipment company.

Challenge
Give managers a quick view of revenue, profit, orders and returns, and let them find what drives the numbers without asking an analyst.
Approach
A star schema with DAX measures for targets and month-on-month change, a what-if price parameter, field parameters and AI visuals.
Result
Readers go from headline KPIs to individual products, customers and regions, and can test how a price change affects profit.

Claude skills for Power BI

Six Claude skills I built for my own Power BI work. They are written in Danish and free to use under the MIT licence.

  • measure-analysis-power-bi (opens in a new tab)

    Audits every DAX measure in a PBIP project, finds unused measures and anti-patterns, and writes a PDF report.

  • measure-excel-power-bi (opens in a new tab)

    Exports all DAX measures to Excel with usage, dependencies, suggested rewrites and DAX Studio checks.

  • pbip-governance (opens in a new tab)

    Documents a PBIP project: data lineage, possible PII columns, RLS and an Azure DevOps wiki.

  • data-modeling (opens in a new tab)

    Builds a gold layer in Power Query and a finished PBIP model from a silver Excel file.

  • data-storytelling (opens in a new tab)

    Guides dashboard design: visual choice per KPI, layout, drill-through and a pre-meeting QA checklist.

  • agent (opens in a new tab)

    Runs the measure skills in sequence on a PBIP project and packs the results with a run log.
